# 程序测试

运行 `make test`。配置测试覆盖默认值、无效环境变量、显式客户端注入和启动校验。工具测试覆盖工具目录、参数契约、底层 HTTP 请求映射和异常透传。使用模拟传输，不修改业务数据。执行器测试覆盖身份、权限、确认、并发去重、结果状态及循环接入，使用模拟 HTTP，不执行真实业务写入。

HTTP 入口测试使用真实 loop/executor 配合模拟模型/业务传输，覆盖多轮历史、查询、确认接续、取消、请求重放、会话隔离、模型失败后的写入去重和 HTTP 访问边界。网站代理测试在 business-demo 中运行，验证登录、CSRF、会话转交及本机地址限制。

日志测试覆盖实际模型请求体记录、脱敏不影响发送内容、确认跨请求关联、重放无重复工具执行、并发上下文隔离、错误记录、日志失败不影响调用、控制台/文件输出与轮转权限。

模型协议测试分别验证 loop 接收独立 FakeModel 的统一响应、拒绝供应商原始字典，以及 OllamaClient 的消息/工具双向转换、调用编号关联与缺失编号补全。既有确认、取消、重放、历史和日志测试继续覆盖新协议。
